# Engineering vocabulary

Use the [project vocabulary](../../CONTEXT.md) for translation concepts.

| Term | Meaning |
| --- | --- |
| Document context | Actual main source, job root, language, sidecars and approved assets |
| Source closure | Ordered included fragments with original file and line locations |
| Publication plan | Complete staged destination set validated before replacement |
| Verification result | Named passed, failed, inconclusive or not-performed check and evidence |

A generated raster enables visual inspection; it does not mean inspection happened.
A successful text probe is not proof of complete scientific fidelity.
