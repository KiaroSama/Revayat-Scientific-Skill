# Domain vocabulary

| Term | Meaning |
| --- | --- |
| Source | Original scientific document and its figures, equations, tables and references |
| Job | Translation with preserved source, terminology and progress records |
| Terms ledger | Per-job decisions with one preferred target form per concept |
| Manifest | Expected figure basenames for inclusion checks |
| Inventory | Source structure and objects the translation must account for |
| Part | Bounded source section with translation and review status |
| Mechanical check | Deterministic validation of spelling, terminology and structure |
| Fidelity review | Comparison of meaning, quantities, uncertainty and references |
| Fluency review | Reading Persian for natural scholarly expression while preserving meaning |
| Verified PDF | Built artifact whose required checks and visual inspection actually ran |
| Source-language profile | The source's language, script, variety and meaning risks used when translating into Persian |
| Protected source span | A quotation, identifier, formula or reference whose original identity must survive translation |
| Coverage map | Correspondence between source locations and their translated or explicitly retained output locations |
| Page geometry | Physical page or book dimensions, orientation and applicable print boxes |
| Image fidelity | Preserved scientific information, pixel detail, aspect ratio and intended printed appearance |
| Image enhancement | A recorded derivative that improves legibility without inventing or changing source evidence |
