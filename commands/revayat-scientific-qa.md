description: Review scientific Persian fidelity, terminology and PDF quality.
argument-hint: [translation path and source path]
---

Use `revayat-scientific` to review `$ARGUMENTS`. Read the skill's `references/review.md`, run its strict checker with the job's level, terms and manifest, compare the translation with the original and inspect rendered pages when a PDF exists. Report findings by consequence, separating meaning, terminology, fluency and presentation. Report unavailable checks. This command reviews; apply changes only if requested.

For QA within a translation job, apply the independent review contract in
`references/multi-agent-workflow.md`. For a standalone review, use the same
located findings format and report who reviewed each part. This command does not
replace missing translation-stage evidence or publish the document.
